HyperCloudHost – karena ini layanan cloud/infrastruktur yang mendukung semua sistem.
Docker – sebagai platform container yang menjalankan MobSF dan aplikasi lainnya di server/cloud.
Cloudflare Tunnel – mekanisme untuk membuka akses publik ke layanan lokal (MobSF/Streamlit).
MobSF – alat utama untuk analisis keamanan APK.
Streamlit – framework untuk membuat web interface agar MobSF dan machine learning dapat diakses interaktif.
Machine Learning – metode prediksi yang digunakan untuk mengevaluasi keamanan APK.
VirusTotal – sebagai alat validasi reputasi file APK.
